# File-management-system

## Project Overview

This project is a lightweight **File Management System** developed to provide a simple and organized way of managing files and folders on a computer.

The system is designed as a desktop application using **Python and Tkinter**, providing a graphical user interface (GUI) that allows users to interact with their files without relying entirely on the command line.

The initial version focuses on establishing the core file-management functionality and creating a simple, user-friendly interface.

## Objectives

The main objectives of the system are to:

* Provide a simple interface for managing files and folders.
* Allow users to browse and navigate through directories.
* Create, rename, move, and delete files and folders.
* Organize files in a structured manner.
* Provide basic file information and management operations.
* Demonstrate how Python can be used to build desktop-based management systems.

## Technology Used

* **Python** – Main programming language.
* **Tkinter** – Used to develop the graphical user interface.
* **OS / Pathlib** – Used to interact with files, folders, and the operating system.
* **VS Code** – Development environment.

## Core Features

The system is intended to provide basic file-management functionality such as:

### File Navigation

Users can browse through directories and view files and folders available on the system.

### File Operations

The application can be developed to support common operations such as:

* Creating files and folders
* Renaming files and folders
* Moving files
* Copying files
* Deleting files
* Opening files

### File Organization

The system provides a simple environment where files can be viewed and organized according to their location and folder structure.

### Graphical User Interface

Tkinter provides the interface through which users interact with the system, reducing the need to perform file-management operations through command-line commands.

## Project Scope

This project is intentionally designed as a **small and practical desktop application**. The initial focus is on understanding file-system operations, GUI development, and how Python can be used to build a functional file-management application.

Future versions can expand the system into a more advanced document and file management platform.
